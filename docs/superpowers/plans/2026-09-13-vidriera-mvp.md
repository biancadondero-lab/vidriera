# Vidriera MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first working version of Vidriera — a static Astro site publishing marketing-news articles across 5 categories, seeded with real content, ready for a future automated-drafting pipeline.

**Architecture:** Astro static site (no backend, no database). Articles live as Markdown files in an Astro Content Collection with an `estado` field (`borrador`/`publicado`) controlling public visibility. Pure filtering/sorting logic is extracted into small, unit-tested functions decoupled from Astro's content APIs; pages are thin glue that call those functions.

**Tech Stack:** Astro 7, Tailwind CSS v4 (via `astro add tailwind`), TypeScript, Vitest (for the pure logic module only).

**Spec:** `docs/superpowers/specs/2026-09-13-vidriera-design.md`

## Global Constraints

- All UI copy and article content is in Spanish.
- No backend, no database — everything is static files in the git repo.
- Only articles with `estado: publicado` may ever appear on public pages.
- Fixed category slugs: `campanas-actuales`, `tendencias-y-datos`, `campanas-historicas`, `redes-y-viralidad`, `marketing-digital` (first two are the visual/editorial priority).
- Site name is "Vidriera" everywhere (page titles, header).
- Visual style: editorial-modern mixed with minimalist-elegant — generous whitespace, a serif display font for headings, a neutral palette with one strong accent color.

Create `src/lib/articles.ts`:

```ts
export type Articulo = {
  id: string;
  titulo: string;
  categoria: string;
  fecha: Date;
  resumen: string;
  fuente?: string;
  estado: 'borrador' | 'publicado';
  imagen?: string;
};

export function filtrarPublicados(articulos: Articulo[]): Articulo[] {
  return articulos.filter((a) => a.estado === 'publicado');
}

export function ordenarPorFechaDesc(articulos: Articulo[]): Articulo[] {
  return [...articulos].sort((a, b) => b.fecha.valueOf() - a.fecha.valueOf());
}

export function filtrarPorCategoria(articulos: Articulo[], categoria: string): Articulo[] {
  return articulos.filter((a) => a.categoria === categoria);
}

export function obtenerPublicadosOrdenados(articulos: Articulo[]): Articulo[] {
  return ordenarPorFechaDesc(filtrarPublicados(articulos));
}
```

En 1988, la agencia Wieden+Kennedy lanzó para Nike el eslogan "Just Do It", inspirado —según contó el propio Dan Wieden— en las últimas palabras de un condenado a muerte en Utah. Lo que empezó como una línea de cierre para una tanda de comerciales terminó convertido en uno de los eslóganes más reconocidos de la historia de la publicidad.

La campaña llegó en un momento en que Nike competía cabeza a cabeza con Reebok y necesitaba algo más que especificaciones técnicas de calzado: necesitaba una emoción. "Just Do It" no vendía zapatillas, vendía una actitud, y funcionó tanto para atletas profesionales como para cualquiera que quisiera empezar a moverse.

Más de tres décadas después, la frase sigue siendo el corazón de la identidad de Nike y es citada como uno de los mejores ejemplos de cómo un buen posicionamiento de marca puede trascender el producto que originalmente promocionaba.
